# Data Warehouse Project (Medallion Architecture)

Welcome to the Data Warehouse Implementation Project built on Microsoft SQL Server using the Medallion Architecture pattern.

---

## About The Project
The main objective of this project is to transform raw data from disparate source systems into a structured, business-ready data model for analytical reporting. The architecture is divided into three core layers:

* **Bronze Layer:** Ingests raw data as-is from source systems using batch processing and full load strategy.
* **Silver Layer:** Cleanses, standardizes, and normalizes data into 3NF while enforcing data quality checks.
* **Gold Layer:** Implements business logic, aggregations, and dimensional modeling (Star Schema) via optimized views.

---

## Requirements
* **Database Engine:** Microsoft SQL Server (SSMS)
* **Code Editor:** Visual Studio Code
